## How to Navigate

1. Open [`Lecture-Notes.md`](Lecture-Notes.md) on GitHub.
2. Use the **Table of Contents** near the top to jump to any lecture or subtopic. You can also use GitHub's outline button (the "list" icon at the top-right of the file view).
3. Each lecture names its **source image** in the `images/` folder so you can compare the notes with the original sheet.
4. Look for the **Verify** warnings (`> [!WARNING]`). They mark text that was cropped, unclear or apparently mis-printed in the source image. Appendix B lists them all.

## Notes

- Code blocks use Python syntax highlighting; program output is shown in separate `text` blocks.
- Callouts (`> [!NOTE]`, `> [!IMPORTANT]`, `> [!WARNING]`) render natively on GitHub.
- Operators "Page 1", and separate lectures on loops, tuples, dictionaries and functions, were not part of the supplied images and are not included.
