## What's Inside `Lecture-Notes.md`

1. Course title and introduction
2. Course information
3. A complete, hierarchical, clickable Table of Contents
4. 20 topics, each containing every related sheet with definitions, tables, Python programs and outputs
5. *Key Takeaways* at the end of every sheet
6. Appendices: source-image index (all 40 images) and a content-verification summary

## How to Navigate

1. Open [`Lecture-Notes.md`](Lecture-Notes.md) on GitHub.
2. Use the **Table of Contents** near the top to jump to any topic, sheet or section, or use GitHub's outline button (the "list" icon at the top-right of the file view).
3. Each sheet names its **source image** in the `images/` folder so you can compare the notes with the original.
4. Look for the **Verify** warnings (`> [!WARNING]`). They mark text that was cropped, unclear or apparently mis-printed in the source image. Appendix B lists them.
